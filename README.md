# SYNC AI – AI-Powered Smart Hackathon Team Matching Platform

## Overview

SYNC AI is a web-based platform designed to help students find suitable teammates for hackathons based on their skills, interests, location, availability, and team requirements.

The platform focuses on creating balanced and compatible teams instead of selecting members only based on high skill scores.

## Problem

Students often face difficulties when participating in hackathons:

* Finding suitable teammates is difficult.
* Teams are often formed only among friends or known students.
* Self-declared skills may not accurately represent actual abilities.
* Beginners may struggle to get opportunities.
* Hackathon information is scattered across different platforms.
* Students may not know which team matches their skills and interests.

## Solution

SYNC AI provides a structured platform where students can:

1. Create an account using college email verification.
2. Complete a skill assessment.
3. Build a student profile.
4. Select preferred technical domains.
5. Discover relevant hackathons.
6. Receive AI-based team recommendations.
7. Express interest in suitable teams.
8. Allow team leaders to accept or reject requests.
9. Track learning progress and improvement.
10. Communicate with team members.

## Key Features

### AI Smart Team Matching

The platform recommends teams using multiple factors such as:

* Verified Skill Score
* Growth Score
* Domain interests
* Communication skills
* Teamwork
* Learning consistency
* Availability
* Location
* Team requirements
* Team vacancies

### Skill Assessment

Students complete assessments covering:

* Coding
* Problem Solving
* Communication
* Teamwork
* Logical Reasoning

The assessment generates a Verified Skill Score.

### Growth and Progress

Students can track their development through:

* Weekly progress
* Learning streak
* XP
* Improvement badges
* Growth Score
* Skill performance

### Hackathon Discovery

Students can discover hackathons based on:

* Domain
* Location
* Online or offline mode
* Deadline
* Prize
* Event type

### Fair Team Formation

The matching system considers different types of learners, including experienced students, consistent learners, improving students, and new participants.

This helps provide opportunities based on compatibility and growth rather than skill level alone.

### Security and Privacy

The platform includes features such as:

* College email verification
* OTP verification
* Timed assessments
* Full-screen assessment mode
* Tab-switch detection
* Private verified skill information
* Protected personal information
* Controlled team communication

The current prototype is developed using HTML, CSS, and Vanilla JavaScript.

LocalStorage is used to demonstrate user data, assessment results, profiles, team matching, notifications, and other application features without requiring a backend server.
